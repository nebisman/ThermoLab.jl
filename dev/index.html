ThermoLab.jl

Laboratorio portátil de control de temperatura.

Este paquete de Julia permite hacer experimentos de control e identificación con la plataforma de experimentación portátil llamada ThermoLab. Esta plataforma integra los componentes para controlar la temperatura de un sistema térmico (un calefactor y un sensor de temperatura DS18B20) por medio de un microcontrolador ESP32.

La plataforma trabaja con un periodo de muestreo de 0.8 s. La temperatura de referencia puede fijarse entre la temperatura ambiente y 90 °C, y la señal de control es la potencia aplicada al calefactor, expresada en porcentaje (entre 0 y 100 %).

Instalación

  1. Instale el firmware de la placa con base en las instrucciones de Instalación del Firmware

  2. Instale el paquete con base en las instrucciones de Instalación del paquete.
