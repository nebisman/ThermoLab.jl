itaemodel

ThermoLab.itaemodel — Function
itaemodel(order=3, omega=1.0; type=:pos)

Calcula la función de transferencia de lazo cerrado de orden order que minimiza el índice $ITAE = \int_0^\infty t\,|e(t)|\,dt$, con frecuencia $\omega_0$ = omega, a partir de los coeficientes normalizados de tabla.

Argumentos

  • order::Int=3: Orden $n$ de la función de transferencia. Con type=:pos admite de 1 a 6; con type=:speed, de 2 a 6.
  • omega::Real=1.0: Frecuencia $\omega_0$ (rad/s) de la respuesta.

Argumentos de palabra clave

  • type::Symbol=:pos: Tipo de respuesta ITAE.

    • :pos: cero error de posición (sigue escalones sin error): $T(s) = \dfrac{\omega_0^n}{D(s)}$
    • :speed: cero error de velocidad (sigue rampas sin error): $T(s) = \dfrac{a_1\,\omega_0^{n-1} s + \omega_0^n}{D(s)}$

    donde $D(s) = s^n + a_{n-1}\,\omega_0\, s^{n-1} + \cdots + a_1\,\omega_0^{n-1}\, s + \omega_0^n$.

Retorna

  • T: Función de transferencia de lazo cerrado candidata, esto es, $T(s)=\frac{Y(s)}{R(s)}$.

Lanza

  • ErrorException si type no es :pos ni :speed, si order está fuera del intervalo admitido para ese type, o si omega no es positiva.

Notas

  • El parámetro omega cambia la velocidad de la respuesta pero no su forma: un valor mayor produce una respuesta más rápida a costa de un mayor esfuerzo de control.
  • itaemodel no diseña un controlador por sí sola: retorna un modelo de lazo cerrado T, el cual debe pasarse luego a cont2dof para obtener el controlador que lo realiza.

Ejemplo

Primero, asegúrese de haber importado el paquete ThermoLab, de haber definido el sistema y de haber obtenido un modelo nominal de dos polos de la planta con get_model_prbs (numpar=3), así:

using ThermoLab
sys = ThermalSystem();
G = tf(sys; numpar=3)

Luego, calcule la respuesta de lazo cerrado ITAE y diseñe el controlador de 2-GDL que la realiza:

ω₀ = 0.8
T = itaemodel(3, ω₀; type=:pos)
C = cont2dof(G, T, 2, [-5*ω₀])

# ahora probamos la respuesta del controlador
set_controller(sys, C)
result = step_closed(sys; r0 = 40, r1 = 50,  t0 = 30, t1 = 30);
stepinfo(result, T)

Para seguir rampas sin error (por ejemplo, con profile_closed) use type=:speed:

T = itaemodel(3, 0.6; type=:speed)
C = cont2dof(G, T, 2, [-3.0])
set_controller(sys, C)
