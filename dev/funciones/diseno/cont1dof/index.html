cont1dof

ThermoLab.cont1dof — Function
cont1dof(G, poles)

Calcula, mediante el método lineal algebraico, un controlador 1-GDL de realimentación unitaria que ubica los polos de lazo cerrado, según los polos indicados por el vector poles.

Argumentos

  • G: Función de transferencia de la planta.
  • poles::Vector: Polos deseados de lazo cerrado del sistema.

Retorna

  • C: función de transferencia del controlador.

Lanza

  • ErrorException si poles no tiene al menos 2n-1 elementos (con n el orden de G), es decir, si el orden del controlador resulta menor que n - 1.

Notas

  • Si selecciona un orden del controlador tal que m > n-1, el algoritmo coloca automaticamente acción integral

en el controlador diseñado.

Ejemplo

Primero, asegúrese de haber importado el paquete ThermoLab, de haber definido el sistema y de haber obtenido un modelo nominal de la planta usando las funciones de identificación get_model_step o get_model_prbs. Así podrá invocar la función de transferencia del sistema con la función tf:

using ThermoLab
sys = ThermalSystem();
G = tf(sys)

Luego, defina los polos deseados de lazo cerrado y diseñe el controlador (con dos polos para la planta de primer orden se obtiene un PI):

polos_lc = [-0.08+0.06im, -0.08-0.06im]
C = cont1dof(G, polos_lc)
set_controller(sys, C)


# Aqui vemos la respuesta al escalon en lazo cerrado
T = feedback(C*G, 1)
result = step_closed(sys; r0 = 40, r1 = 50,  t0 = 60, t1 = 120);
stepinfo(result, T)
