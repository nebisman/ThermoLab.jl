lqmodel

ThermoLab.lqmodel — Function
lqmodel(G, q)

Calcula, por factorización espectral, la respuesta de lazo cerrado óptima LQ para la planta G, que minimiza el índice cuadrático

$J = \int_0^\infty \left( q\,e^2(t) + \tilde u^2(t) \right) dt$

donde $e = r - y$ es el error de seguimiento y $\tilde u$ la desviación de la señal de control respecto a su valor final. Los polos de T son las raíces estables de $D(s)D(-s) + q\,N(s)N(-s)$, con $G = N/D$.

Argumentos

  • G: Función de transferencia de la planta.
  • q::Real: Peso del error de seguimiento en el índice cuadrático (relativo al peso unitario de la señal de control).

Retorna

  • T: Función de transferencia de lazo cerrado, esto es, $T(s)=\frac{Y(s)}{R(s)}$, con los mismos ceros de G y ganancia estática unitaria.
  • Gur: Función de transferencia de referencia a señal de control (u = Gur·r).

Notas

  • Un valor de q mayor penaliza más el error, produciendo una respuesta de lazo cerrado T más rápida a costa de un mayor esfuerzo de control; un valor de q menor produce una respuesta más lenta pero con menor esfuerzo de control. Gur permite revisar ese esfuerzo (por ejemplo, con step(Gur)) antes de probar el controlador.
  • lqmodel no diseña un controlador por sí sola: retorna un modelo de lazo cerrado óptimo T, el cual debe pasarse luego a cont2dof para obtener el controlador que lo realiza.

Ejemplo

Primero, asegúrese de haber importado el paquete ThermoLab, de haber definido el sistema y de haber obtenido un modelo nominal de la planta, así:

using ThermoLab
sys = ThermalSystem();
G = tf(sys)

Luego, calcule la respuesta de lazo cerrado óptima LQ y diseñe el controlador de 2-GDL que la realiza:

Tlq, Gur = lqmodel(G, 10)
C = cont2dof(G, Tlq, 2, [-0.3, -0.3])

# ahora probamos la respuesta del controlador
set_controller(sys, C)
result = step_closed(sys; r0 = 40, r1 = 50,  t0 = 60, t1 = 120);
stepinfo(result, Tlq)
