cont2dof

ThermoLab.cont2dof — Function
cont2dof(G, T, m, polesobs=[])

Calcula, mediante un método lineal algebraico, un controlador de dos grados de libertad (2-GDL) que hace que la respuesta de lazo cerrado para la planta G se ajuste con una función de transferencia deseada T elegida por el diseñador.

Argumentos

  • G: Función de transferencia de la planta, de orden n.
  • T: Función de transferencia de lazo cerrado deseada.
  • m::Int: Orden del controlador. Debe ser al menos n-1.
  • polesobs::Vector=[]: polos del observador, que se cancelan en la respuesta de la referencia a la salida. Su número debe ser n + m - gr(T/N), con gr(T/N) el grado del denominador de $T(s)/N(s)$ una vez cancelados los términos comunes.

Retorna

  • C: matriz de transferencia 1×2 del controlador, definida como:

    $C(s) = \begin{bmatrix} \dfrac{L(s)}{A(s)} & -\dfrac{M(s)}{A(s)} \end{bmatrix}$

    La señal de control es $u = \frac{L}{A} r - \frac{M}{A}y$. Este controlador se carga directamente en la plataforma con set_controller.

Lanza

  • ErrorException si m < n-1 (el orden del controlador es menor que el mínimo requerido, n-1, con n el orden de G).
  • ErrorException si polesobs no tiene exactamente la longitud requerida por el grado del polinomio $T(s)/N(s)$; el mensaje indica cuántos polos hacen falta.

Notas

  • Si selecciona un orden del controlador tal que m > n-1, el algoritmo coloca automáticamente acción integral ($A(0) = 0$) en el controlador diseñado.
  • Las funciones lqmodel e itaemodel pueden ayudar a escoger un modelo T.

Ejemplo

Primero, asegúrese de haber importado el paquete ThermoLab, de haber definido el sistema y de haber obtenido un modelo nominal de la planta usando las funciones de identificación get_model_step o get_model_prbs. Así podrá invocar la función de transferencia del sistema con la función tf:

using ThermoLab
sys = ThermalSystem();
G = tf(sys)

Luego, defina la respuesta de lazo cerrado deseada (por ejemplo, una función de segundo orden) y diseñe el controlador de 2-GDL:

s = tf("s");
ωn = 0.1; ζ = 0.8
T = ωn^2 / (s^2 + 2ζ*ωn*s + ωn^2)
C = cont2dof(G, T, 2, [-0.3])

# ahora probamos la respuesta del controlador
set_controller(sys, C)
result = step_closed(sys; r0 = 40, r1 = 50,  t0 = 60, t1 = 120);
stepinfo(result, T)
