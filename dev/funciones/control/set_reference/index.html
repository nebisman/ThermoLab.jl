set_reference

ThermoLab.set_reference — Function
set_reference(sys::ThermalSystem, ref_value::Real=40.0)

Fija la referencia de temperatura de la plataforma ThermoLab al valor ref_value (en °C). El controlador activo (ver set_pid y set_controller) lleva la temperatura a ese valor.

Argumentos

  • sys::ThermalSystem: objeto que representa la plataforma.
  • ref_value::Real=40.0: temperatura de referencia, en °C. No debe superar los 90 °C.

Retorna

  • nothing. Como efecto secundario, imprime en consola la referencia fijada.

Lanza

  • ErrorException si ref_value es mayor que 90 °C.

Ejemplo

using ThermoLab
sys = ThermalSystem();
set_reference(sys, 50.0)

    "Referencia fijada a 50.00 °C"
