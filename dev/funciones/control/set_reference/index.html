set_reference

ThermoLab.set_reference — Function
set_reference(sys::ThermalSystem, ref::Real)

Fija la referencia de temperatura de la plataforma ThermoLab en ref (°C). El controlador cargado en la plataforma (PID o general, ver set_pid y set_controller) lleva la temperatura a ese valor y la mantiene allí.

Argumentos

  • sys::ThermalSystem: objeto que representa la plataforma.
  • ref::Real: temperatura de referencia, en °C. Debe estar entre la temperatura ambiente y 90 °C (MAX_TEMPERATURE).

Retorna

  • nothing. Imprime en consola la referencia fijada.

Notas

  • Al recibir una nueva referencia el firmware reinicia el estado del controlador (por ejemplo, la acción integral del PID).
  • Todos los experimentos de este paquete fijan la referencia en 40 °C (DEFAULT_REFERENCE) al terminar.

Ejemplo

using ThermoLab
sys = ThermalSystem();
set_reference(sys, 50.0)

    Referencia fijada en 50.0 °C
