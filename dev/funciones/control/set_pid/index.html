set_pid

ThermoLab.set_pid — Function
set_pid(sys::ThermalSystem; kp=16.796, ki=2.0, kd=16.441, N=27.38, beta=0.1)

Esta función configura los cinco parámetros kp, ki, kd, N y beta de un controlador PID de 2-GDL (dos grados de libertad), como el mostrado en la siguiente figura:

Argumentos

  • sys::ThermalSystem: objeto que representa la plataforma ThermoLab.

Argumentos de palabra clave

  • kp::Real=16.796: ganancia proporcional del controlador PID.
  • ki::Real=2.0: ganancia integral del controlador PID.
  • kd::Real=16.441: ganancia derivativa del controlador PID.
  • N::Real=27.38: coeficiente del filtro del derivador.
  • beta::Real=0.1: ponderación del punto de ajuste (setpoint weighting) del controlador PID.

Retorna

  • nothing, una vez que los parámetros del PID se han actualizado correctamente. Imprime en consola los parámetros configurados.

Notas

  • Cuando beta=1.0, el PID resultante corresponde al PID estándar de un grado de libertad (1-DOF) descrito en la mayoría de los libros de texto.
  • Esta implementación se basa en el algoritmo formulado en el libro Feedback Systems: An Introduction for Scientists and Engineers, segunda edición, de Åström y Murray. El algoritmo usa un periodo de muestreo del controlador de 0.8 segundos, apropiado para la plataforma ThermoLab, e incluye un mecanismo anti-windup para la acción integral.
  • La potencia aplicada se satura entre 0 y 100 %.
  • Al cargar el controlador, la referencia vuelve al valor por defecto de 40 °C.

Ejemplo

Primero, asegúrese de haber importado el paquete ThermoLab y de haber definido el sistema, así:

using ThermoLab
sys = ThermalSystem();

Luego, el controlador PID se programa así:

set_pid(sys; kp=11.8, ki=2.7, kd=0, N=10.0, beta=0.0)

    "PID actualizado: kp=11.8  ki=2.7  kd=0  N=10.0  β=0.0"
