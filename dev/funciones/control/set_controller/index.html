set_controller

ThermoLab.set_controller — Function
set_controller(sys::ThermalSystem, controller)

Programa un controlador general en la plataforma ThermoLab. El controlador se define como una función de transferencia continua en la variable de Laplace s, la cual se discretiza automáticamente.

Esta función permite programar un controlador estándar de 1 grado de libertad (1-GDL), como el mostrado en la siguiente figura:

A su vez, esta misma función permite programar un controlador de 2 grados de libertad (2-GDL), como se muestra a continuación:

Argumentos

  • sys::ThermalSystem: objeto que representa la plataforma.

  • controller: función o matriz de transferencia continua (ControlSystemsBase.TransferFunction, o cualquier sistema LTI convertible con ss).

    • Si $C$ es 1×1 (una entrada y una salida), se interpreta como controlador de 1-GDL:

      $u = C\,(r - y)$

    • Si $C(s) = \begin{bmatrix} \dfrac{L(s)}{A(s)} & -\dfrac{M(s)}{A(s)} \end{bmatrix}$ es una matriz 1×2 (dos entradas y una salida), se interpreta como controlador de 2-GDL, cuya señal

    de control se obtiene como:

    $u = \frac{L}{A} r - \frac{M}{A}y$

    Por ejemplo, el controlador que retorna cont2dof tiene la forma $C(s) = \begin{bmatrix} \dfrac{L(s)}{A(s)} & -\dfrac{M(s)}{A(s)} \end{bmatrix}$ .

Retorna

  • nothing. Imprime en consola el tipo y el orden del controlador cargado.

Notas

  • El controlador se lleva a una realización mínima en espacio de estados, se discretiza con el método bilineal (Tustin) con periodo de muestreo de 0.8 s.

  • Se implementa un mecanismo anti-windup basado en un observador, cuya ganancia se calcula mediante el filtro de Kalman; la potencia aplicada se satura al intervalo $[0, 100]$ %. Este mecanismo se describe en Åström y Wittenmark (1997), Computer-Controlled Systems.

Referencias

  • Åström, K. J. y Wittenmark, B. (1997). Computer-Controlled Systems: Theory and Design, 3.ª ed. Prentice Hall, Upper Saddle River, NJ.

Ejemplos

Ejemplo 1: controlador de un grado de libertad (1-GDL)

Supongamos que queremos implementar el controlador PI

$C(s)=10 + \frac{2}{s}$

Para ello usamos el siguiente código:

using ThermoLab
sys = ThermalSystem();
s = tf("s");
C = 10 + 2/s;
set_controller(sys, C)

Ejemplo 2: controlador de dos grados de libertad (2-GDL)

El controlador de 2-GDL puede diseñarse, por ejemplo, con cont2dof:

using ThermoLab
sys = ThermalSystem();
G = tf(sys; numpar=3)
T = itaemodel(3, 0.8)
C = cont2dof(G, T, 2, [-4.0])
set_controller(sys, C)
