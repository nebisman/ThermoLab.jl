set_controller

ThermoLab.set_controller — Function
set_controller(sys::ThermalSystem, controller)

Programa un controlador en la plataforma ThermoLab. El controlador se define como una función de transferencia en el dominio de Laplace s, la cual es automáticamente discretizada.

Esta función permite programar un controlador estándar de 1 grado de libertad (1-GDL), como el mostrado en la siguiente figura:

A su vez, esta misma función permite programar un controlador de 2 grados de libertad, como se muestra a continuación:

Argumentos

  • sys::ThermalSystem: objeto que representa la plataforma ThermoLab.

  • controller: función de transferencia continua (ControlSystems.TransferFunction) en el dominio de Laplace s.

    • Si $C$ es 1x1 (una entrada y una salida), se interpreta como controlador de 1 grado de libertad:

      $u = C·(r - y)$

    • Si $C=[C_1\quad C_2]$ es una matriz 1×2 (dos entradas y una salida), se interpreta como controlador de 2 grados de libertad:

      $u = C_1·r + C_2·y$

      Con el controlador obtenido por cont2dof, $C_1=\frac{L}{A}$ es la primera columna y $C_2=-\frac{M}{A}$ es la segunda.

Retorna

  • nothing. Imprime un mensaje de confirmación en consola.

Notas

  • Esta función admite tanto controladores de 1-GDL como de 2-GDL, de orden máximo 10.
  • El controlador se convierte a espacio de estados para su implementación digital. Se discretiza usando el método bilineal (Tustin) con un periodo de muestreo de 0.8 segundos.
  • Se implementa un mecanismo anti-windup basado en un observador, cuya ganancia se calcula mediante el filtro de Kalman.
  • La potencia aplicada se satura entre 0 y 100 %.

Ejemplos

Ejemplo 1: controlador de un grado de libertad (1-GDL)

Supongamos que queremos implementar un controlador PI para la temperatura de la plataforma ThermoLab, definido por la siguiente función de transferencia:

$C(s)=\frac{11.8\,s + 2.7}{s}$

Para ello usamos el siguiente código:

using ThermoLab
sys = ThermalSystem();
s = tf("s");
C = (11.8s + 2.7)/s;
set_controller(sys, C)

    "Controlador cargado en ThermoLab"

Ejemplo 2: controlador de dos grados de libertad (2-GDL)

Supongamos que queremos implementar un controlador de 2-GDL diseñado con cont2dof para que la temperatura siga una respuesta de lazo cerrado de segundo orden T:

using ThermoLab
sys = ThermalSystem();
G = tf(sys)
s = tf("s");
ωn = 0.1; ζ = 0.8
T = ωn^2/(s^2 + 2ζ*ωn*s + ωn^2)
C = cont2dof(G, T, 1, [-0.3])
set_controller(sys, C);

    "Controlador cargado en ThermoLab"
