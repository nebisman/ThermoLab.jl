power_from_temp

ThermoLab.power_from_temp — Function
power_from_temp(sys::ThermalSystem, temp::Real)

Estima la potencia constante (en % de la potencia máxima) necesaria para que la plataforma ThermoLab alcance, en estado estacionario, la temperatura temp (en °C). Es la función inversa de temp_from_power y usa el mismo modelo estático lineal obtenido con get_static_model:

$\qquad \text{\texttt{power}} =\dfrac{\text{\texttt{temp}} - b}{K}$

Argumentos

  • sys::ThermalSystem: objeto que representa la plataforma

  • temp::Real: temperatura de estado estacionario especificada (en °C). Debe cumplir que

    $b \leq$ temp $\leq 90\,°C$ (MAX_TEMPERATURE)

    donde $b$ es la temperatura estimada sin potencia aplicada (temperatura ambiente).

Retorna

  • Float64: potencia estimada (en %) requerida para alcanzar la temperatura de estado estacionario definida en la variable temp, saturada al intervalo $[0, 100]$.

Lanza

  • ErrorException si temp está fuera del intervalo indicado.

Ejemplos

using ThermoLab
sys = ThermalSystem();
power_from_temp(sys, 50.0)

    20.09

El valor depende del modelo estático guardado en la carpeta datafiles.
