get_last_model

ThermoLab.get_last_model — Function
get_last_model(sys::ThermalSystem; numpar::Int=2)

Retorna la función de transferencia y el retardo de la plataforma ThermoLab, estimados previamente con get_model_step o get_model_prbs. La salida del modelo es la temperatura (°C) y la entrada es la potencia aplicada (% de la potencia máxima).

Argumentos

  • sys::ThermalSystem: objeto de la plataforma (no necesita estar conectado; solo se usa para ubicar el archivo del modelo).

Argumentos de palabra clave

  • numpar::Int=2: número de parámetros del modelo a usar.

    • numpar=2 (por defecto): modelo de un polo, estimado por get_model_step o por get_model_prbs con numpar=2:

      $G(s)=\dfrac{b}{s+a}$

    • numpar=3: modelo de dos polos, estimado por get_model_prbs con numpar=3:

      $G(s)=\dfrac{b}{(s+a_1)(s+a_2)}$

Retorna

  • G::ControlSystemsBase.TransferFunction: función de transferencia continua del sistema térmico.
  • L::Float64: retardo estimado, en segundos. Si el modelo se obtuvo con PRBS el retardo es de una muestra (0.8 s).

Ejemplos

sys = ThermalSystem();
G, L = get_last_model(sys)              # modelo de 1 polo (por defecto)
G2, L = get_last_model(sys; numpar=3)   # modelo de 2 polos
